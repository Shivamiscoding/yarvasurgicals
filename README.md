# Yarva Surgicals — Official Healthcare & Surgical Consumables Website

Professional web platform and catalog showcase for **Yarva Surgicals**, a surgical consumables and medical equipment distributor based in Pune, Maharashtra.

> **Tagline:** Quality • Care • Better Tomorrow  
> **Central Office & Warehouse:** H No 1534 Lawale Phata, Balaji Nagar, Pirangut, Mulshi, Pune, Maharashtra 412115  
> **Certifications:** ISO 9001:2015, ISO 13485:2016, Indian Pharmacopoeia (I.P.) Compliant

## 🏥 Featured Product Range

1. **Absorbent Gauze Swabs (Sterilized)**
   - 100% Pure Absorbent Cotton
   - 5cm × 5cm × 12 Ply (4 Pcs peel-pouch / hospital master carton)
   - Ethylene Oxide (ETO) Sterilization with steam/EO chemical indicator
   - ISO 13485:2016 certified sterile barrier packaging

2. **Absorbent Cotton Wool I.P.**
   - Indian Pharmacopoeia (I.P.) compliant
   - 400g Net Weight (500g Gross)
   - Hyper cleanliness, high absorbency (<10s sinking time), luxurious softness, odorless
   - Suitable for hospital OT dressing rooms, wards, and clinical fluid management

3. **Cotton Crepe Bandage**
   - 10cm × 4m (Stretched Length)
   - Packaged in a protective transparent airtight container with moisture-lock green lid
   - High elasticity, firm therapeutic compression & warmth, hypoallergenic and skin-friendly
   - Fast selvedge non-fraying edges, washable & reusable

## 🚀 Key Features

- **Exact Brand Identity & Color Palette:** Derived directly from the Yarva Surgicals logo (Deep Navy `#0b2545`, Medical Teal `#028090`, Clean White `#ffffff`, and Soft Mint `#e0f2f1`).
- **1-Scroll Product Showcase:** The landing page hero leads directly with a scroll cue into the 3 featured products with specifications, highlights, and certifications.
- **Empty Facility Trailer:** A dedicated video tour player placeholder for cleanroom walkthroughs and sterilization demos, equipped with a customizable URL embed setting.
- **Interactive Quotation Trailer (Dock):** A persistent quotation trailer that tracks requested wholesale lots, lets procurement officers adjust quantities, and generate 1-click WhatsApp RFQs or formal tender inquiries.
- **Verified Clinical Credentials:** ISO 9001:2015, ISO 13485:2016, Indian Pharmacopoeia standards, and GST compliance.
- **Full Contact & Pune Location Integration:** Direct Google Maps link to Pirangut, Mulshi, Pune, phone, WhatsApp desk, and email.

## 💻 Quick Start

### 1. Run Development Server:
```bash
cd yarvasurgicals
npm run dev
```
or from the root workspace:
```bash
npm run dev
```

### 2. Build for Production:
```bash
cd yarvasurgicals
npm run build
```
